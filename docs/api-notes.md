## 기본

## 엔드포인트

| 용도 | 요청 | 비고 |
|---|---|---|
| 전체 항목 목록 | `GET /api/articles?p={pageNo}&ps={pageSize}` | `body`·`footNote`·`reference`는 빈 문자열 |
| 항목 검색 | `GET /api/articles/search?q={keyword}&p=&ps=` | 항목명 기준으로 보임 (아래) |
| 항목 내용 | `GET /api/articles/{eid}` | 본문 포함. 「가경전」(E0000027) 8KB, 0.14초 |
| 미디어 3종 | `/api/medias`, `/api/medias/search`, `/api/medias/{mid}` | 쓰지 않는다 (이용 조건, `decisions.md` 1-1) |

## 페이지 처리

목록·검색 응답의 바깥 구조:

```json
{"currentCount": 20, "totalCount": 15836, "pageNo": 1, "pageSize": 20, "totalPage": 792,
 "items": [...], "requestUrl": "/api/articles", "queryString": "?p=1&ps=2"}
```

- `ps`가 20보다 작으면 20으로 맞춘다 (`ps=2` → 20개).
- `ps`는 1000까지 그대로 받았다. 크게 주면 느려진다 (각 1회 측정, 요청 사이 1초 간격):

| `ps` | 크기 | 응답 시간 |
|---|---|---|
| 50 | 97KB | 0.25초 |
| 100 | 183KB | 0.56초 |
| 200 | 374KB | 20.6초 |
| 500 | 948KB | 26.3초 |
| 1000 | 1.9MB | 43.9초 |

→ 목록 수집은 `ps=100` (전체 159페이지).

호출 한도(분당·일일)는 안내 페이지에 없고, 아직 걸린 적도 없다.

## 항목 필드

목록과 내용 응답의 필드 구성은 같다. 목록 첫 페이지 20개 기준으로 비어 있는 수를 적었다.

| 필드 | 형식 | 예 | 빈 값 (목록 20개 중) |
|---|---|---|---|
| `eid` | `E` + 7자리 | `E0000025` | 0 |
| `url` | 항목 페이지 | `https://encykorea.aks.ac.kr/Article/E0000025` | 0 |
| `headword` | 항목명 | `가거도 멸치잡이노래` | 0 |
| `origin` | 한자 표기 | `可居島 멸치잡이노래` | 3 |
| `headwordOrigin` | 항목명(한자) | `가거도 멸치잡이노래(可居島 멸치잡이노래)` | 0 |
| `field` | `큰 분류/세부 분류` | `역사/조선시대사` | 0 |
| `primaryTypePartA`·`B`, `primaryType` | 유형 | `작품` / `전통음악` / `작품/전통음악` | B만 4 |
| `secondaryType` | 보조 유형 | `시도무형유산` | 0 |
| `contentsType` | 유형 합친 문자열 | `작품/전통음악, 시도무형유산` | 0 |
| `era` | 시대 (아래) | `조선/조선 전기 \| 조선/조선 후기` | 0 |
| `definition` | 정의 한 문장 | | 0 |
| `summary` | 요약 문단 | | 2 |
| `body` | 본문 Markdown (아래) | 「가경전」 1,961자 | 목록에선 항상 빈 값 |
| `footNote` | 각주 | `[^1]: …` | 목록에선 항상 빈 값 |
| `reference` | 참고문헌 Markdown | `## 원전\r\n- 『세종실록』…` | 목록에선 항상 빈 값 |
| `writerInfo` | 집필자 | `김혜정(경인교육대학교)` | 0 |
| `lastModifiedTime` | 수정 시각 (시간대 없음) | `2026-09-18T11:05:44.07` | 0 |
| `headMID`, `headMedia` | 대표 미디어 | 없으면 `00000000-…`, `null` | headMedia 14 |
| `articleAliases` | 별칭 `[{word, aliasType, …}]` | `가거도 멸치잡이 뱃노래` | 12 |
| `articleAttributes` | 속성 `[{groupName, attrName, …}]` | `groupName: 작품/전통음악` | 8 |
| `hashtags`, `relatedArticles`, `relatedMedias` | 목록 | | 목록에선 20 |

- `lastModifiedTime`의 소수 자릿수가 항목마다 다르다 (22자·23자).
- `articleAliases`는 별칭형 질문(3-1)과 사실 데이터(4-2), `articleAttributes`는 사실 추출(4-1) 후보다. 속성 구조는 4-1에서 자세히 본다.

### `era`

- 여러 시대는 ` | `(공백·세로선·공백)로 구분한다. 각 시대는 `큰 시대/세부 시대`.
- 본 값: `고려/고려 전기`, `고려/고려 후기`, `고려/고려 전기 | 고려/고려 후기`, `조선/조선 전기`, `고대/삼국/고구려`(3단), `선사/청동기`, `근대/일제강점기`, `현대`, `미상`.
- 고려시대 판정: ` | `로 나눈 시대 중 **하나라도** 첫 단이 `고려`인 것.
  첫 시대만 보면 안 된다. 「태조」(왕건, E0059032)는 `고대/남북국 | 고려/고려 전기`라서 빠진다.
- `field`도 여러 값을 ` | `로 잇는다. 예: 「태조」(묘호, E0059034) `역사/고대사 | 역사/고려시대사 | 역사/조선시대사`.

### `body` (Markdown)

```
# 개설
조선시대에는 원칙적으로 20년마다 [양전](E0035725)을 실시하여 …
… 원전(元田)[^1]과 대비되어 …
```

| 표기 | 의미 |
|---|---|
| `# 개설`, `# 내용` | 소제목 → 섹션 경로 |
| `[양전](E0035725)` | 다른 항목 링크 (괄호 안이 `eid`) |
| `[^1]` | 각주 표시. 내용은 `footNote`의 `[^1]: …` |

- 줄바꿈: `body`는 `\n`, `footNote`·`reference`는 `\r\n`.
- 공백 두 칸(`작성된  『경자양안』`) 같은 원문 그대로의 흔적이 있다.

## 검색

| `q` | `totalCount` | 결과 |

| `왕건` | **0** | 없음. 항목명이 「태조」(E0059032)이고 "왕건"은 `articleAliases`에만 있다 |

→ "왕건"처럼 별칭으로 묻는 질문은 `articleAliases`로 풀어야 한다 (`embedding_text` 접두사, 5-4 질의 재작성).

## 열린 문제

1. **API 목록이 전체의 일부다.** `totalCount` 15,836건. 공공데이터포털 목록은 73,587건 (약 22%).
   목록 첫 페이지는 `E00000xx`부터, 검색 결과에는 `E0072xxx`~`E0080xxx`가 많다.
2. ~~「왕건」이 검색되지 않는다.~~ **풀림.** 항목명이 「태조」(E0059032)라서 그렇다.
   `/api/articles/E0059032`는 HTTP 200, 본문 2,818자로 정상이다.
3. **확인 결과 (1-3, 2026-10-08): API는 목록의 15,836건만 내용을 준다.**
   - 전체 목록 159페이지(`ps=100`)를 받았다. 15,836건, `eid` 중복 없음, 번호 범위 `E0000025`~`E0081607`.
   - 웹사이트에 있는 「강감찬」(E0000954)·「노비안검법」(E0012765)은 목록에 없고,
     `/api/articles/{eid}`가 **HTTP 204, 본문 0바이트**다. 목록 번호 사이의 빈 번호 10개도 모두 204.
   - 고려 항목(`era`에 고려가 하나라도 있음) 1,602건. 인물 363, 제도 314, 유적 298, 문헌 250, 작품 205, 사건 39.
   - 대표 항목 있음: 「태조」(왕건), 「광종」, 「서희」, 「공민왕」, 「묘청의 난」, 「무신란」, 「구주대첩」, 「후삼국 통일」, 「과거」.
     없음: 「노비안검법」, 「강감찬」(인물. 「강감찬 설화」만 있음), 「삼별초」.
   - 집계: `uv run python src/phase1/list_stats.py`
